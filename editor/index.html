Pickups

Choose Place pickup, then click its road module. Click a marker or choose a pickup above to select it. Fields set new placements; Update selected applies edits. Along runs from the piece's first port to its second, independent of race direction. Leave 2 m from road edges. Erasing a module also removes its pickups after confirmation.

Click to place. Occupied cells are never replaced: erase or rotate them explicitly. Set the start on a straight, with a heading along its road.

Red dots mark disconnected road ends. Unfinished drafts can be saved; only a valid closed circuit can be generated.

Save, generate and play

Save JSON to a chosen location (for example track/layouts/my_circuit.json). The editor never writes workspace files, runs Blender or installs tracks.

blender --background --factory-startup --disable-autoexec \
  --python-exit-code 1 --python tools/build_modular_track.py -- \
  track/layouts/my_circuit.json

Use a new track ID to preserve reference tracks. See README.md for installation, backups and the one-way Blender handoff.
